# Nyembesi EOI Programme Portal

**Nyembesi Corporate Services | Pan-African B2B Commodities & Trade Platform**

This repository contains the live EOI Programme Portal — tracking all 55 AfCFTA member state Expression of Interest letters.

## How it works

- `index.html` — the full portal. Edit this file to update the live website.
- Changes pushed to the `main` branch automatically deploy to Netlify within ~30 seconds.
- No build step required — pure HTML, deploys instantly.

## Updating the portal

1. Download the latest `index.html` from Claude
2. Replace the file in this repository
3. Commit and push to `main`
4. Netlify auto-deploys — website updates live
